## Production implementation

### Active files

- `RTL/VGA/jungle_head_draw.sv`
  - Directly instantiates the approved Emerald 9-bit sprite atlas.
  - Selects native Up, Right, Down, and Left head sprites.
  - Preserves the existing registered-ROM and output-register VGA latency.
  - Remains visual-only; the established `headBitMap` collision path is unchanged.
- `RTL/VGA/snake_body.sv`
  - Directly instantiates the same Emerald atlas.
  - Uses adjacent trail positions to select vertical/horizontal body segments, all four corner orientations, and all four tail orientations.
  - Preserves the original trail, movement, growth, shrinkage, maximum length, and self-collision logic.
  - Safely handles one-segment and 32-segment snakes without out-of-range trail access.
- `RTL/mifs/snake_variants/01_emerald_rgba9.mif`
  - Approved source data used without pixel modification.
  - SHA-256: `259581F27E1A4A1B12A2C48DD289D50C4BA7DC7F56380D7280DE319EC4038611`.
  - Width 9, depth 8064: bit 8 is opacity and bits 7:0 are RGB332.
  - Addressing is `sprite_index*576 + y*24 + x` for fourteen 24×24 sprites.
- `simulation/snake_sprite_variants_tb.sv`
  - Retained filename for continuity, but its active module is now the production-only `snake_emerald_production_tb`.
  - Covers all sprite orientations, addresses, alpha/color latency, length effects, bounds, and self-collision independence.
- `simulation/snake_emerald_production.do`
  - Reproducible focused ModelSim production test with no variant macro.

The compile-time variant selector was removed from active renderer RTL. The normal QSF has no snake-variant macro, and the fitter report references only `01_emerald_rgba9.mif`; Guardian, Viper, Mystical, and Stone MIFs are not instantiated.

No gameplay controller, BDF interface, arena/HUD/relic/opening/results/audio logic, timing constraints, PLL, score logic, or pin assignment was changed. The score-90 victory condition remains intact.

### Timing

Constrained internal timing closes with no negative slack:

- Worst setup slack: **+5.151 ns** (Slow 1100 mV, 85°C).
- Worst hold slack: **+0.120 ns** (Fast 1100 mV, 0°C).
- TNS: **0.000 ns** for every reported setup and hold corner.

These values demonstrate closure for the constrained internal clock domain only. Existing external-I/O limitations remain:

- 0 unconstrained clocks, but 5 unconstrained input ports / 120 input paths.
- 55 unconstrained output ports / 141 output paths.

- The legacy `DE10_Standard_Audio.sdc` still contains unmatched or ignored audio, VGA, DRAM, and JTAG constraints, including two ignored generated-clock constraints.
- Existing incomplete drive-strength/slew-rate assignments and five combinational loops analyzed as latches remain reported.
